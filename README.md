# Ich schaffe das — A1 test IPA

v37: Twenty short Kokoro teaching prompts and fifteen recorded reactions; reset returns to Lesson 1 Card 1, and only the dark mouth opening moves. Download the unsigned IPA from the latest successful Actions run and sign it with Sideloadly.

This iPhone test app signs in with Google and opens the learner's first unfinished A1 card. Completing A1 opens the separate A1+ revision course. Existing lesson text, vocabulary, quizzes, answers, flags, and scoring remain in place.

Cards 1–20 have friendly teacher explanations generated once with the existing ClipStudio Kokoro worker. They play automatically and offer pause, replay, and a written transcript. Six supplied portraits rotate across the cards; a small four-shape mouth overlay moves while the teacher audio plays. The portrait map supports additional images and per-card assignments without generating animation files. The previous cutout animations, YouTube Shorts, and games are removed from the app. The teacher audio and portraits are bundled, so playback does not call an AI service.

The initial button opens settings with monthly leaders, personal points, a reset-progress action, and sign-out. Reset clears A1 and A1+ completion, quiz answers, and points for that Google account.

The IPA is unsigned. Download the newest successful `ich-schaffe-das-a1-v35-unsigned-ipa` artifact from [GitHub Actions](https://github.com/prashanttalreja1985-boop/ich-schaffe-das-a1-test/actions/workflows/build-ipa.yml), unzip it, and open `Ich-schaffe-das-A1-v35-unsigned.ipa` in Sideloadly. Google OAuth remains in test mode, so the Google account must be on the Cloud project's test-user list.

The [v35 source archive](ich-schaffe-das-a1-source-v35.zip) contains the Flutter app, scripts, MP3s, supplied portraits, and tests. This is a public repository, so its bundled portraits are publicly visible.
